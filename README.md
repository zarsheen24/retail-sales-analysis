# Retail Sales Data Analysis

## Overview
This project analyses a retail sales dataset to identify trends, patterns, and key business insights. The goal is to demonstrate data cleaning, analysis, and visualisation skills using Python.

---

## Dataset
- Source: Superstore Sales dataset (Kaggle)
- Size: ~10,000 rows
- Features: Sales, Profit, Category, Region, Order Date

---

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

---

## Key Tasks
- Cleaned and prepared raw data (handled missing values and formatting issues)
- Performed exploratory data analysis (EDA)
- Analysed sales trends over time
- Identified top-performing and underperforming product categories

---

## Key Insights
- Sales increased during Q4 (holiday season)
- Certain product categories generated higher profit margins
- Some regions showed high sales but lower profitability

---

## Files
- analysis.ipynb (main analysis)
- data.csv (dataset)
- README.md (documentation)
